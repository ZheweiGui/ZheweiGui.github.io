# Zhewei Gui — Personal Website

Source for my personal academic website, featuring research in dexterous manipulation, robot learning, reinforcement learning, and sim-to-real systems.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Updating

Edit the files in this repository, then run:

```bash
git add .
git commit -m "Update website"
git push
```
